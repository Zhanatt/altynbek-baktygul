# Приглашение на той — Алтынбек & Бактыгүл (15.11.2026, ресторан «Аяр», Бишкек)

Статичный сайт (HTML + CSS + JS, без сборки), сделан по образцу `~/wedding-invite`.
Кыргызский по умолчанию, кнопка КЫР/РУС. Фон насыщенно-красный `--red`, буквы цвета шампань `--champagne` (начало `style.css`).
Стиль — по видео-примеру ES-WEDDING (своя графика): конверт с лентами крест-накрест и сургучом, шёлк, змейка «Тойдун тартиби» с розой, линейный рисунок ресторана, «Кошумча маалымат» — карточка на затемнённом фото ужина (photo-2) с двумя плашками, дресс-код.
Черновые тексты, ждут подтверждения: программа (15:00/16:00/17:00/23:00; торта нет), два пункта «Кошумча маалымат», цвета дресс-кода (шампань, пудра, бордо, чёрный, коричневый, золотистый, #6B0818, #94B1C8). Фото пары: обложка — img/hero.jpg (ч/б), карточки — img/photo-1.jpg, photo-2.jpg (EXIF удалён). Примеры нарядов — добавить, когда пришлют.
Имена и заголовки — Playfair Display Italic (было: Bad Script — по просьбе заменён на более читаемый).

## Анкета → Google Таблица

Так же, как в `~/wedding-invite/README.md`: таблица → Расширения → Apps Script → вставить `google-apps-script/Code.gs`
→ Развернуть как веб-приложение (доступ: Все) → URL вписать в `CONFIG.rsvpEndpoint` в `app.js`.
Пока URL пустой, форма показывает ошибку при отправке.

При правке CSS/JS менять `?v=` у `style.css` и `app.js` в `index.html` — иначе у гостей останется старый кэш.

Музыка — Maher Zain «For The Rest Of My Life», официальный клип через плеер YouTube (`CONFIG.youtubeId`), кнопка звука справа внизу.

Иконки — линейные, цвета шампань, встроены в `app.js` (ICONS): Tabler Icons (MIT), Hugeicons «wedding» (MIT), Lucide Lab «flower-rose-single» (ISC). Цветные 3D-эмодзи пользователь отверг — нужен стиль самого сайта.
Шрифт заголовков и имён — Playfair Display Italic (читается, есть ү ө ң).
