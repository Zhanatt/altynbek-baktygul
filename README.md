# Приглашение на той — Алтынбек & Бактыгүл (15.11.2026, ресторан «Аяр», Бишкек)

Статичный сайт (HTML + CSS + JS, без сборки), сделан по образцу `~/wedding-invite`.
Кыргызский по умолчанию, кнопка КЫР/РУС. Фон насыщенно-красный `--red`, буквы цвета шампань `--champagne` (начало `style.css`).
Стиль — по видео-примеру ES-WEDDING (своя графика): конверт с лентами крест-накрест и сургучом, шёлк, змейка «Тойдун тартиби» с розой, линейный рисунок ресторана, «Кошумча маалымат» в тёмном зале со свечами и лучами, дресс-код.
Черновые тексты, ждут подтверждения: программа (15:00/16:00/17:00/23:00; торта нет), два пункта «Кошумча маалымат», цвета дресс-кода (шампань, пудра, бордо, чёрный, коричневый, золотистый, #6B0818, #94B1C8). Фото пары и примеры нарядов — добавить, когда пришлют.
Имена — рукописный Bad Script (в нём есть «ү»; в Marck Script и Great Vibes её нет).

## Анкета → Google Таблица

Так же, как в `~/wedding-invite/README.md`: таблица → Расширения → Apps Script → вставить `google-apps-script/Code.gs`
→ Развернуть как веб-приложение (доступ: Все) → URL вписать в `CONFIG.rsvpEndpoint` в `app.js`.
Пока URL пустой, форма показывает ошибку при отправке.

При правке CSS/JS менять `?v=` у `style.css` и `app.js` в `index.html` — иначе у гостей останется старый кэш.

Музыка — Maher Zain «For The Rest Of My Life», официальный клип через плеер YouTube (`CONFIG.youtubeId`), кнопка звука справа внизу.
